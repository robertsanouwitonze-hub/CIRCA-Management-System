# CIRCA updated website prototype

## Files
- `index.html`: public CIRCA homepage
- `academy.html`: CIRCA Academy platform admin dashboard concept
- `school-login.html`, `teacher-login.html`, `parent-login.html`: login page placeholders
- `styles.css`, `script.js`, `favicon.svg`: shared assets

## Important
This is a frontend prototype. The Academy invitation form generates a local demo configuration, **not a real registration link**. No authentication, database, email delivery, school verification or access-control backend is connected. Before production, implement secure authentication, single-use expiring invitation tokens, server-side approval, tenant isolation, role-based authorization and audit logging.

Open `index.html` to view the site, or `academy.html` to view CIRCA Academy.
